# Project Management Plan – Final version (15/11/2026)

This is the final version of the Project Management Plan for Release 1.0. The seven parts below are the plan version 1.0 submitted in Sprint 1 (29/10/2026), updated with the approved change requests and the lecturer's feedback during the project. Every part keeps its own version history. On 17/11/2026 the whole plan was rewritten in plain language: abbreviations are written out in full and GitHub terms are replaced by plain descriptions, so that readers who do not use GitHub or Jira can follow it. Only identifiers of user stories, test cases, requirements, change requests, defects, risks, issues and lessons are kept.

## Changes since plan version 1.0
| Part of the plan | Change in the final version | Reason |
